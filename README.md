## ✨ Возможности

### 👨‍🏫 Для наставников:
- 📝 **Регистрация** с указанием ФИО, организации, должности, города, телефона и пароля
- 🔑 **Вход** по телефону и паролю
- 🔄 **Сброс пароля** через СМС-код
- 📚 **Управление курсами** — создание, редактирование, удаление курсов с уроками
- 📝 **Задания** — назначение заданий всей группе или конкретным ученикам
- 👥 **Управление группой** — отметка посещений, выставление оценок
- 👁 **Профили учеников** — просмотр информации, успеваемости, рейтинга, данных родителей
- 🏫 **Код класса** — уникальный 6-значный код для присоединения учеников

### 🎓 Для учеников:
- 🎫 **Присоединение по коду класса** от наставника
- 📝 **Регистрация** с указанием фамилии, пароля, ФИО и телефона родителя
- 🔐 **Логин** = фамилия + порядковая цифра (автоматически при совпадениях)
- 🏠 **Лобби** — просмотр заданий, курсов, рейтинга, посещаемости
- 👤 **Профиль** — информация о родителях, наставнике, успеваемости

## 🔐 Система авторизации

### Регистрация наставника:
1. ФИО
2. Организация
3. Должность
4. Город
5. Телефон (используется как логин)
6. Пароль

### Вход наставника:
- Телефон + пароль
- Сброс пароля через СМС-код

### Регистрация ученика:
1. Код класса (от наставника)
2. Фамилия (логин = фамилия + цифра при совпадениях)
3. Пароль
4. ФИО родителя
5. Телефон родителя

### Вход ученика:
- Логин (фамилия) + пароль

## 💾 Хранение данных

Все данные хранятся в **localStorage** браузера:
- `vox_mentors` — список наставников
- `vox_students` — список учеников
- `vox_courses` — курсы
- `vox_assignments` — задания
- `vox_current_user` — текущий пользователь
- `vox_sms_codes` — СМС-коды для сброса пароля
